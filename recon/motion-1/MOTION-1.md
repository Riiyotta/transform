# Motion-1 verification (clone http://127.0.0.1:5179 vs live https://www.transform9.com)

Method: the live values were read from the live runtime (`window.ScrollTrigger.getAll()`, `gsap.getTweensOf`, timeline children and `window.lenis.options`; see `live-runtime-internals.json`). Then `verify.mjs` ran identical sampling on both sites: rAF sampling of computed styles after a programmatic scroll, hover or click, plus settled reads. `compare.py` diffs the results into `summary-clone-<W>.json`. Trigger start/end positions are in `triggers-{clone,live}-<W>.json`, and all 11 triggers are equal at 1440, 1024, 768 and 390. The resize check (`resize.mjs`) and the on-white menu and reduced-motion checks (`extra.mjs`) are separate scripts. The clone's 11 ScrollTriggers are not duplicated under StrictMode.

## Deviations / notes
1. M18 cycle 1: on live the cross snaps to 1 on the very first open (IX2 first-run quirk). The clone always runs the measured 100ms-after-100ms tween, which matches live cycles 2 and later.
2. M9 card trigger positions are computed from the cards' natural (untransformed, un-stuck) boxes rather than from `getBoundingClientRect`. The values equal live at all widths on a fresh load. This keeps positions correct when ScrollTrigger refreshes mid-deck; without it, 1440→390→1440 left card 2/3 triggers off by 18–67px in some runs.
3. The M9 timelines replicate IX3 call for call (`to` and empty-start `fromTo` with `stagger {each:0}`), so start values are recorded lazily, as on live. After large jumps across the deck, intermediate values inside the 57px ranges, and the residues visible when scrolled back above a trigger at 768, depend on frame timing on both sites (e.g. live −7.43 vs clone −8.10px in one run and equal in another). Sequential scrolling and every settled end state are identical.
4. `.is-hidden` (M3) and `.is-on-white` (M4) remain as QA state hooks. They are committed after the tween (onComplete/onReverseComplete) so they never leak into GSAP's recorded start values. `data-active` / `.is-active` (M7) and `data-stack-step` / `data-depth` / `.is-stacked` (M9) stay at their static initial values, and GSAP inline styles carry the state.
5. Clone-only: `html[data-menu-open="true"|"false"]` for Motion-2's M10 pause, and `window.__motion` (dev builds only) for these scripts.
6. Lenis 1.3.26 (installed) instead of 1.0.23. The options are the same and the wheel curve is identical. `html.lenis-smooth` is managed by Lenis 1.3 itself, so it is not permanently present as on live. No CSS depends on it.
